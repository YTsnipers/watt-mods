A Claude Code mod

watt shows what Claude Code leaves hidden

Tool call times, a chip for each running subagent, live progress bars and a usage line after every turn, drawn in the terminal next to the prompt. The scene below replays one turn: Claude fixes a login redirect with three subagents.

Settings

Five things watt adds to the terminal

took 0.4s

Tool call times

Each finished tool call ends with how long it took. A call that is still running stays as Claude Code draws it.

agent row

A chip per subagent

Each chip shows the agent's model, its elapsed time and how much of its context it has used (the brighter part). Finished chips turn green or red and stay 20 s, or until you press ×. The pill on the left counts finished agents.

plan_progress

Live progress bars

For multi-step work Claude keeps a bar with the stage, the step and the share done. Orange while it works, green when done, red when a step fails.

ctx · 5h · 7d

A usage line after each turn

Tool time, model time, cache hits, the context used against the model's own window, and five-hour and seven-day usage. Orange past 25% context or 60% usage, red past 35% or 80%.

sounds

Sounds when work ends

A soft chime when a long turn or all subagents end, an error tone when something failed, a decision tone when Claude waits for you. Press Sound above to hear them in the replay.

/watt-settings

Every effect can be turned off

Twinkle, sounds, the model on chips, and how long finished chips and bars stay. The same options sit under watt in /config.

Install in one line

/plugin install watt --marketplace YTsnipers/watt-mods

Needs Claude Code 2.1.295 or newer. watt also asks Claude to keep a progress bar for multi-step work and adds about 150 tokens of rules to each request; the README lists every change it makes. Source: github.com/YTsnipers/watt-mods.

The progress bar, the agent chips and the summary pill in this replay are drawn by watt's own raster.ts and track.ts, compiled for the browser, cell for cell. Claude Code's own lines around them (tool rows, the prompt box) are a mock. Times in the replay run three times faster than shown.
