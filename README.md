# watt-mods

Claude Code mods by apollon.

| Mod | What it does |
| --- | --- |
| [watt](plugins/watt) | Tool call times, a turn line with context and usage, a chip per running subagent, and live progress bars above the prompt, with soft sounds when work ends, fails or waits for you. |

## Install

In Claude Code:

```
/plugin install watt --marketplace YTsnipers/watt-mods
```
